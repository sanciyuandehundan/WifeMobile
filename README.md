# WifeMobile

她在手机上。两种情况：

- **在电脑旁**：手机当你的耳机和麦克风。你的声音进电脑上 Wife 的语音识别，她的声音从手机出来（手机做回声消除）。
- **不在电脑旁**：手机直接拨家里的电脑，和平时一样跟电脑上的她说话，她知道你在外面。连不上电脑时，可以叫醒**手机上的她**：用数据线把电脑上的模型文件拷进手机的“下载”：`WifeBody/models/brain-candidates/qwen2.5-7b-instruct/` 下的两个 GGUF 分片，和 `WifeBrain/output/wife-v24-q4/epoch2/wife-chat.gguf`（共 4.8 GB），再在 App 里点“选择大脑文件”选中它们，App 把它们复制进自己的存储（别用 adb 往 `Android/data/io.wife.mobile` 里放：安卓会重建那个文件夹，里面的东西一起删掉）。llama.cpp 按 i8mm 编译（骁龙 8 Gen 1 及以后），更老的手机跑不了手机上的她。

## 还没有的

- 离线时和手机上的她说的话，回家后还不会进电脑上她的记忆。
- 离线时她的声音是手机系统的朗读，不是她的声音；离线也只能打字。
